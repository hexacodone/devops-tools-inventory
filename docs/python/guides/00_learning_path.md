# Python Learning Path — Start Here

A beginner-oriented Python vocabulary series, built by digesting real working code (`temp/detection_rule.py`) instead of abstract examples. Read the files in this order:

1. **[01_python_fundamentals.md](01_python_fundamentals.md)** — values, collections, and the small building blocks (`return`, f-strings, `list`/`dict`/`tuple`/`set`, comprehensions, error handling, common built-ins) you need before functions or classes make sense.
2. **[02_modules_and_libraries.md](02_modules_and_libraries.md)** — organizing code into files, and using code other people wrote (`pydantic` as the running example).
3. **[03_classes_and_objects.md](03_classes_and_objects.md)** — defining your own custom data types: `class`, `self`, `__init__`, methods, attributes.
4. **[04_inheritance_and_class_tools.md](04_inheritance_and_class_tools.md)** — extending classes (inheritance), decorators, enums, constants, and naming conventions.

Each file is a flat list of short term → definition entries, not prose to read straight through — treat it as a reference to skim once and revisit.

**Not yet covered (planned for a future file):** variables and basic data types (`str`/`int`/`float`/`bool`), operators, and control flow (`if`/`else`, `for`, `while`). Those are genuine day-one basics; they'll get their own entry once we work through them.
